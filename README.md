# cfp11d2026

Basic C++ programming exercises for CFP11 class.

## Quick Start (Browser-Based)

No installation needed! You can complete all tasks directly in your web browser:

- **[cpp.sh](https://cpp.sh/)** - Simple C++ editor and compiler
- **[OneCompiler](https://onecompiler.com/cpp)** - Online C++ IDE with built-in compiler

## How to get started

1. Visit [cpp.sh](https://cpp.sh/) or [OneCompiler](https://onecompiler.com/cpp)
2. Choose a task from [TASKS.md](TASKS.md)
3. Write or modify the C++ code in the browser
4. Click compile/run to test your solution
5. Once it works, submit a Pull Request with your code
